# Dev Stack — Modern Tech Stack Builder

An interactive web application designed for developers and engineering teams to explore, compare, and assemble their ideal development stack.

## Key Features

- Interactive technology stack builder with duplicate prevention
- Real-time stack counter and dynamic empty state
- Fully responsive across desktop, tablet, and mobile devices
- Centralized brand gradient theme
- Feedback alerts powered by `react-toastify`

## Built With

- React.js (Vite)
- Tailwind CSS
- React-Toastify
